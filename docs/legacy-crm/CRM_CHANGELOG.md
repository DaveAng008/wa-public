# 🚀 Chatwoot Kanban Pro - 核心更新日志 (Changelog)

本项目已从一个单纯的看板展示工具，进化为一套支持 **MySQL 原生驱动**、**SLA 自动化对流** 以及 **SaaS 商业化管控** 的企业级 CRM 协同中心。

---

## 📅 2026-04-15 | v15.0 - 工作流自动化巅峰版
### 🌟 核心更新 (Core Updates)
- **[新增] SLA 3.0 阶梯式工作流自动化引擎**：
    - 支持三级阶梯 (T1/T2/T3) 顺序触发逻辑。
    - **懒触发 (Lazy-Trigger) 机制**：采用前端静默扫描技术，无需服务器配置 Cron，卡片满足阈值自动执行“动作”。
    - **自动化动作**：支持自动升级优先级 (Priority Upgrade) 和 跨阶段移位 (Auto-Move)。
- **[新增] 智能倒计时勋章**：卡片实时计算下一级自动化的剩余时间，显示为 `🤖 剩 Xh Ym 升级`。
- **[优化] 批量导入算法**：重写了 Excel/表格数据的智能解析引擎，支持 Tab 和逗号混合分隔符。
- **[视觉] 阶梯 UI 板块**：在设置面板中新增了可折叠的自动化配置区，支持呼吸灯状态显示。

## 📅 2026-04-14 | v13.6 - SaaS 商业套件与废品回收
### 🌟 核心更新 (Core Updates)
- **[新增] 闲置回收站 (Trash Bin)**：
    - 引入“软删除”机制，避免误操作导致客资流失。
    - 支持 **“物理销毁 (🔥)”** 与 **“长按复活”** 操作。
- **[新增] SaaS 商业化守护模块**：
    - **体验期黄条**：实时显示剩余体验天数。
    - **物理销毁警告页**：针对严重逾期账户触发全屏红色脉冲警告，切断非必要的 API 调用。
    - **死亡锁定屏**：当 `destroy_at` 时间到达后，系统自动熔断数据通道，显示注销界面。
- **[优化] 性能调优**：实现了 **指纹比对 (Fingerprint Comparison)** 机制，数据无变化时禁止重绘 DOM，大幅降低手机端发热。

## 🧠 Antigravity 的看法 (Observations)

1. **“懒触发”是神来之笔**：
   在常规 CRM 中，自动化通常依赖服务器复杂的 `crontab` 任务，这会增加运维成本。我们采用的 **前端静默扫描 + 后台静默 API 调用** 的方案，不仅节省了服务器开销，还让用户在操作看板时能实时看到“自动化的发生”，这种交互感极佳。

2. **从“展示工具”到“生产工具”的转变**：
   通过加入“手动新增”、“批量导入”和“状态标签管理”，系统已经具备了生产力闭环。它不再仅仅是用来“看”数据的，而是用来“管理”和“作业”的。

3. **建议关注：垂直化深挖**：
   现在的架构已经非常稳固。建议下一步将重心放在**“详情页 (Task Details)”**上。目前点击卡片没有反应，如果能做一个深度详情页，让用户能记录“每一次跟进的电话小记”，那么这套系统将正式具备挑战市面上主流收费 CRM 的实力。
